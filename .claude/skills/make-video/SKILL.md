# make-video

영상 한 편 = BRIEF → 레퍼런스 정리 → 장면표 → 스냅보드 → 영상. 기준은 `CLAUDE.md`.

## 1. BRIEF (직접 묻기)
세 가지만 하나씩 묻고, 기본값을 같이 제안한다.
1. **무엇을** 보여줄까? (기본값: `docs/design.md` 6장 화면 중 하나의 기능 소개)
2. **몇 초**? (기본값: 15초)
3. **레퍼런스**는? 링크 · 파일 · 없음 (기본값: `references/`에 있는 것)

영상이름(영문 소문자-하이픈)을 정해 `out/<영상이름>/brief.md`에 쓴다. 이미 있는 이름이면 다른 이름을 제안한다.

## 2. 레퍼런스 정리
`art-director` 에이전트 → `out/<영상이름>/refs.md`.
"새 후보"가 있으면 사용자에게 기본값과 함께 묻고, 정해지면 `docs/motion.md`나 `docs/video.md`에 날짜와 함께 적는다.

## 3. 장면표 — 승인 1
`director` 에이전트 → `out/<영상이름>/scenes.md` 3안.
사용자에게 3안 요약을 보여주고 하나를 고르게 한다. 고르기 전에는 넘어가지 않는다.

## 4. 스냅보드 — 승인 2
`builder` 에이전트 → `out/<영상이름>/snapboard/`.
`critic` 에이전트로 판정 → 통과하면 보드를 보여주고 승인을 받는다.

## 5. 영상
`builder` 에이전트 → `out/<영상이름>/video/` 렌더.
`critic` 에이전트로 판정 → 통과하면 렌더 파일 경로를 알려준다.

## 공통
- 불통과면 builder가 판정 줄만 보고 고친 뒤 다시 판정. 같은 곳 2번 불통과면 멈추고 묻는다.
- 단계마다 끝에 "지금 어디까지 했고 다음은 무엇인지" 한 줄로 알려준다.
